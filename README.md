# LoGO: Local Deltas + Global Offsets for L1D prefetching

CS683 course project (Mradul Sonkar). Checkpoint 1: characterize the gap Berti
(a per-IP delta prefetcher) leaves, and how much of it a global best offset
(BOP) could recover.

Findings: [results/SUMMARY.md](results/SUMMARY.md). Charts: `results/w50M_s200M/plots/`.

## Layout

| Path | What |
|---|---|
| `Berti-Artifact/ChampSim/Berti/` | Simulator: the Berti authors' ChampSim (MICRO'22 artifact, [agusnt/Berti-Artifact](https://github.com/agusnt/Berti-Artifact) @ `5db2457`), trimmed to what we build |
| `…/prefetcher/bop.l1d_pref` | BOP, written from Michaud, HPCA'16 |
| `…/prefetcher/berti_gap.l1d_pref` | Berti + gap counters (generated by `scripts/make_berti_gap.py`) |
| `…/prefetcher/ip_stride.l1d_pref` | IP-stride (authors' file, fixed to compile in this version) |
| `scripts/` | build, download, run, parse, plot, analyze |
| `traces.txt` | The 9 traces used |
| `results/w50M_s200M/` | Raw simulator logs, CSVs, charts |

## Reproduce

Needs GCC 7.5 as the default `g++`, Python 3, about 5 GB of disk and ~3 hours on 6 cores.

```bash
scripts/download_traces.sh                       # 9 traces -> traces/
scripts/build_all.sh                             # 5 simulators -> bin/
scripts/run_batch.sh 50000000 200000000 6 nopf ipstride bop berti bertigap
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/parse_results.py
.venv/bin/python scripts/plot_results.py
.venv/bin/python scripts/analyze_ips.py
```

Setup: 50M warmup + 200M simulated instructions, single core, all prefetchers at L1D.
